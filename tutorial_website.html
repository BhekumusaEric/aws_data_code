🚀 Quick Start Guide

Get up and running in just 5 minutes:

  1. Launch the System: Run streamlit run predictive_intervention_system.py
  2. Choose Your Role: Select Teacher, Parent, or Administrator view
  3. Explore Sample Data: Familiarize yourself with the interface using demo data
  4. Take a Tutorial: Complete the role-specific tutorial for your needs
  5. Start Using: Begin with real student data and create your first intervention plan
