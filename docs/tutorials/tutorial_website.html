🚀 Quick Start Guide

Get up and running in just 2 commands:

  1. Install Dependencies: pip install streamlit plotly pandas numpy boto3
  2. Launch System: python -m streamlit run main.py
  3. Open Browser: Navigate to http://localhost:8501
  4. Start Tutorial: Click the welcome banner or tutorial button
