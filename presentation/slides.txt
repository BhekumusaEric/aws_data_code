# Slide 3: Our Solution

**Student Insights Pipeline**
A lightweight, serverless data pipeline that:

* Ingests student performance data in real-time
* Analyzes it for trends and risks
* Surfaces tailored insights to support each learner

---

# Slide 4: How It Works

**End-to-End Data Pipeline**

1. **Ingest** – Lambda/API Gateway receives student data
2. **Store** – Amazon S3 stores raw and transformed data
3. **Transform** – Cleaned via AWS Glue or Python
4. **Analyze** – Athena queries surface insights
5. **Visualize** – Optional QuickSight dashboards for educators
